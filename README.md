# 考研备考工作台

一个简洁清爽的个人「备考工作台」，帮你备考 12 月研究生考试：每天记录学习、复盘错题、追踪进度。核心功能是**错题四栏归因法 + 上传图片记录错题/知识图片**。

纯前端 · 零依赖 · 浏览器直接打开即用 · 数据本地保存，可随时导出备份。

---

## 立即使用

直接用浏览器打开 `index.html` 即可（手机可拍照、电脑也可用）。建议用本地服务器方式以获得最佳体验：

```powershell
# 在项目根目录启动静态服务
python -m http.server 8080
# 浏览器打开 http://localhost:8080/
```

## 功能一览

| 页面 | 说明 |
|:---|:---|
| 首页 | 考研倒计时、目标院校/分数、今日任务、学习时长、本周完成率、四科进度 |
| 学习计划 | 任务增删改（截止时间/优先级/完成状态），首页今日任务联动 |
| 科目进度 | 英语/政治/数学/专业课四科进度与阶段管理 |
| 真题管理 | 简要记录真题（时效/得分/错题数） |
| 模考成绩 | 成绩记录 + 按科目趋势 |
| **错题簿** | **核心**：「四栏归因法」记录错题 + 拍照上传题目图 + 复发记忆 + 薄弱点统计 + 按科目/掌握度筛选 + **错题复习（间隔递增提醒 + 红点徽标）** + **错题排行榜（复发次数 Top10）** |
| 资料库 | 图文资料 + 标签 + 搜索 |

### 错题簿 · 四栏归因法

一条错题 = 题目图片 + 四栏：

| 栏 | 内容 |
|:---|:---|
| ① 题目·知识点 | 题干关键词（不抄全题） |
| ② 我错在哪 | 可多选：概念不清 / 计算失误 / 审题漏条件 / 记错公式 / 时间不够 / 其他 |
| ③ 关键一步 | 正确路径中最容易断掉的那步 |
| ④ 复发次数 | 每做错一次「再错+1」；连错 ≥3 次自动标记「永久保留」 |

还支持：薄弱点统计（自动按错误类型聚合）、按科目分类、按「未掌握/复发中/已掌握/永久保留」筛选（复习连续做对 3 次自动标记「已掌握」）。

### 错题复习与排行榜

- **错题复习**：三标签「待复习 / 全部 / 排行榜」。到期未复习的错题进入待复习队列（侧栏与手机底部 Tab 红点徽标显示数量，点击直达）；间隔自适应递增 3→5→7→10→14→21→30 天；复习 = 重做一遍，标记「做对了」（间隔递增）或「又做错了」（再错 +1、间隔回 3 天重学，连错 ≥3 次自动永久保留）；逾期 1 天黄 / 3 天橙 / 7 天红分级提醒。
- **错题排行榜**：按「再错 +1」累计的复发次数降序取 Top 10，前三名 🥇🥈🥉，高频错题一目了然。

## 数据与备份

- **结构化数据**：保存在浏览器 `localStorage`（key: `kylc:data`）
- **图片**：保存在浏览器 `IndexedDB`（database: `kylc-images`）
- 数据都在**本机浏览器**内，换浏览器或清缓存会丢失——**请定期备份**：

侧栏底部有「导出数据」按钮（下载 JSON 备份）与「导入备份」（恢复）。备份文件同时包含结构化数据和图片。

## 技术要点

- HTML + CSS + 原生 JS，无框架、无构建步骤
- 响应式：桌面侧栏 / 手机底部 Tab，触屏友好
- 架构：`store`（持久层）→ `controller`（状态+事件总线）→ `views`（渲染）→ `router`（切换）

## 目录结构

```
index.html          入口
css/                base / layout / components
js/
  utils.js          工具（倒计时/日期/时长/常量）
  store.js          localStorage + IndexedDB 封装
  controller.js     状态管理与事件总线
  ui.js             弹窗/图片/文件助手
  views/*.js        各页面（dashboard/plan/subject/pastPaper/mockExam/material/wrongBook）
  router.js         页面切换
  app.js            入口装配
docs/specs/         需求与技术方案
```

## 说明

- 现代浏览器（Chrome/Edge/Firefox/Safari 近版本）适用，不兼容 IE11。

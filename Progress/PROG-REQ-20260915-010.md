## 进度日志

### 2026-09-15 — 确认

- 用户把 REQ-009 的三态开关升级为**双态日蚀式**：浅/深两态，切换时日月变形、云层视差、切到夜间时星星「被吹出」呈失重漂浮感、平时轻柔闪烁。
- 经提问确认四口径：只留浅/深（旧 `auto` 归浅色）；桌面 pill + 手机 Tab 各放一个；星星仅切换瞬间漂浮 + 平时轻柔闪烁；美化范围 += 看板统计数字增长、进度条完成轻弹、空状态图标浮动。

### 2026-09-15 — 实现

- `store.js`：`theme` 默认 `'auto'` → `'light'`；`migrate` 增 `if (settings.theme === 'auto') settings.theme = 'light'`。
- `ui.js`：`applyTheme` 双态（dataset + theme-color meta + 开关 dark class / aria-pressed）；新增日蚀开关 `themeToggleHTML(mode,size)`（seedRand 种子随机保证双端星星分布稳定不闪变）、`starHTML`（`--sx/--sy` 起点 + 曲径 keyframes + 独立 twinkle 定时）、`countTo`（rAF + ease-out + reduced-motion 兜底）、`animateCounts`。
- `app.js`：移除三态循环与 matchMedia 监听；桌面注入 lg 开关；事件委托点击切换（加 `switching` 微模糊 460ms → `updateSettings` → `applyTheme` → Toast）。
- `router.js`：底部 Tab 注入 sm 开关；`renderNav` 末 `UI.applyTheme(tMode)` 对齐双端。
- `index.html`：`#btnTheme` → `#themeToggleDesktop.tt-slot` 插槽。
- `components.css`：日蚀开关全套（track 天空渐变 + 日辉/月旋钮 + 日冕光晕淡出 + 月牙淡入 + 三层云 `cloudDrift` 视差 + `starIn` 吹出 + `starTwinkle` 闪烁 + `switching` 模糊）；`.empty .empty-icon` `emptyFloat`；`.progress > i.is-full` `barPoof`。
- `layout.css`：`.tab-theme` 手机 Tab 开关布局。
- `dashboard.js`：统计数字加 `data-count`，首次入场数字滚动 + 满格进度条加 `is-full` 轻弹（`animated` 只播一次）。

## 发现的既有问题（已确认并修复：BUG-20260915-003）

- **桌面端汉堡按钮可见**：`.btn { display:inline-flex }`（components.css）与 `.sidebar-toggle { display:none }`（layout.css）同优先级，但 components.css 后加载导致覆盖失效。
- `git show HEAD:` 证实上个提交即如此，REQ-008 桌面实测时未检查此项，故一直未被发现。
- 副作用：桌面点汉堡会给侧栏加 `open` class，触发非媒体查询的 `.sidebar.open + .sidebar-mask` 规则 → 全屏黑蒙层。
- **修复（用户确认后实施）**：layout.css 两条规则改 ID 选择器 `#btnToggleSide`（优先级高于类选择器，不受加载顺序影响）。
- **修复验证**：Edge 1280x800 实测按钮 `display:none`、点击主区无蒙层、路由正常；headless 双视口探针确认手机端（390px）按钮仍可见、媒体规则命中（计算值 `flex` 为 topbar flex 容器对子项的正常块化，非异常）；console 零报错。详见 `Requirements/BUG-20260915-003.md`。

# PROG-REQ-20260916-002 复习队列防堆积（每日限量 + 逾期智缓）

## 目标
在**不改复习间隔数据、不丢任何复习任务**的前提下，让每日实际要做的题量可承受、流动，让真正生疏的题永远排前。

## 阶段进度

### 阶段 1：需求与技术方案
- 状态：已完成
- 产物：`Requirements/REQ-20260916-002.md`
- 关键口径：
  - 稳定掌握判定 = 30天档(reviewCount>=6) + 最近连续2次对 + 逾期<=7天 + 非permanent
  - 每日受理上限：-1=自适应(近14天中位数clamp[5,300]) / 0=不限 / >0=固定
  - 排序：逾期大优先 → 到期早次级；稳定题淡出至收纳区；做错自动回归

### 阶段 2：实现
- 状态：已完成
- 改动：
  - `js/store.js`：settings 新增 `dailyReviewCap:-1`，migrate 自动兜底零迁移
  - `js/utils.js`：新增 `isStabilized()` 稳定判定、`dailyCapValue()` 上限解析
  - `js/controller.js`：重写为 `reviewDueQueue()`（active/deferred/stabilized 三分区）、`reviewDueList` 复用、`reviewDueCount` 返回真实到期总数(红点不受限)
  - `js/views/wrongBook.js`：renderReviewTab 重构为活动区+顺延折叠区+稳定收纳折叠区
  - `js/views/dashboard.js`：设置页新增「每日复习受理上限」(留空=自适应/0=不限/数字=固定)
  - `css/components.css`：新增 `.rv-more` 折叠区样式

# 需求 REQ-20260915-012 错题卡片显示添加时间 + 排序切换

> 分类：功能优化 · 影响范围：js/utils.js + js/views/wrongBook.js + css/components.css
> 状态：已完成 · 最后更新：2026-09-15

## 一、背景与目标

用户反馈：错题添加后看不到时间，错题多了之后分辨不出哪些是比较新收录的。

调研确认：错题数据**本就存放** `created`（创建时间）与 `updated`（更新时间）字段，添加时自动写入；列表也一直按 `updated` 降序排列，只是**卡片界面未展示时间**，用户无从判断新旧。

## 二、口径（用户本次明确确认）

用户选定「**卡片显示时间 + 排序切换（推荐）**」：

| 决策点 | 结论 |
|---|---|
| 卡片展示 | 每张错题卡片顶部显示添加时间，格式为相对时间（刚刚 / N分钟前 / N小时前 / N天前 / 月-日 时:分，跨年带年份），并配日历图标 |
| 排序切换 | 「全部错题」Tab 筛选区下方新增「最近操作 / 按添加时间」两档切换；默认「最近操作」= 按 `updated` 降序（维持现状）；「按添加时间」= 按 `created` 降序 |
| 排序方向 | 排序条右侧新增方向切换「最新在前 / 最早在前」（默认最新在前=降序；切到最早在前=升序），免去往下滑才看得到最早错题的麻烦；方向与字段可自由组合 |
| 兼容性 | 历史旧数据无 `created` 时回退用 `updated` 显示与排序，保证既有数据不丢、不崩 |
| 数据影响 | 无（纯展示与排序，不动 localStorage 结构） |

## 三、改动清单

| 层 | 文件 | 改动 |
|---|---|---|
| 工具 | `js/utils.js` | 新增 `relTime(ts)`：相对时间文案（跨年带年份） |
| 视图 | `js/views/wrongBook.js` | 新增 `sortBy` 状态（update/created）、`sortDir` 状态（desc/asc）与统一排序函数 `sortWrong`；「全部错题」Tab 加排序切换条与方向切换；卡片顶部加 `.wc-time` 添加时间；排序与方向点击就地更新胶囊/按钮并只刷新结果区保留输入焦点 |
| 样式 | `css/components.css` | 新增 `.wc-time` 行内对齐样式 |

## 四、验证口径

- `node --check` 改动的 2 个 JS 文件通过。
- 本地静态服务 + 无头浏览器播种 3 条不同 `created` 错题实测：
  1. 卡片顶部显示日历图标 + 相对时间文案；
  2. 切换条默认「最近操作」高亮，方向按钮默认「最新在前」；
  3. 「按添加时间」+ 方向切换到「最早在前」后，最早的错题排最前，无需下滑即可看到；
  4. 字段切换、方向切换可自由组合、往返切换稳定；console 全程零报错。

## 1. 背景与目标

备考工作台已完成错题收录、复习闭环（F-08）、到期提醒与排行榜。本轮在用户选定的三个方向上增强：

1. **复习闭环的深度** → 复习历史轨迹（PRD「可后续扩展」项）
2. **进度与数据洞察** → 学习统计看板（新「数据」入口）
3. **人性化激励与习惯** → 每日复习目标

不引入 P2 错题抽测、P4 连续打卡（YAGNI，留待后续）。

## 2. 确认口径

- 范围：P1 复习历史轨迹 + P3 学习统计看板 + P5 每日复习目标 + **导出/导入适配新版存储**。
- 不做：抽测模式、连续打卡、图片压题、多用户/云同步、后端。
- 数据影响：动存储（见 §4 schema），已与用户确认。
- 验收标准：复习后卡片出现轨迹与正确率；首页显示今日复习 x/目标 y，达成有鼓励；新增「数据」页展示复习趋势/掌握度/薄弱点；导出→清空→导入后数据与图片完整、旧备份可无损导入。

## 3. 功能规格

### P1 复习历史轨迹
- 每次复习（`markReviewed`）追加一条 `{ at, correct }` 到该题 `reviewHistory`，上限 30 条（超出丢最旧，防存储膨胀）。
- 错题卡（全部 / 待复习）底部展示最近数次复习轨迹：✓/✗ 彩色标记 + 日期 + 累计正确率（做对次数 / 复习次数）。
- 复习弹窗内展示历史摘要，辅助决定「做对了 / 又做错了」。

### P5 每日复习目标
- `settings.dailyReviewGoal`（0=未设置）。
- 首页新增「今日复习目标」卡：显示 `今日复习 x / 目标 y`，进度条；`今日复习数` = 当天（`toDateStr(at)` 今天）的 `reviewHistory` 条数总和，跨题累计。
- 目标在「目标设置」弹窗内新增输入项。
- 达成（y>0 且 x≥y）时卡片高亮「🎉 已达成」。

### P3 学习统计看板
- 新增侧栏/手机 Tab 入口「📊 数据」（路由 `#/stats`）。
- 全部由现有数据派生，只读，不改存储：
  - **复习趋势**：近 14 天每日复习次数柱状图（来自各题 `reviewHistory`）。
  - **各科掌握度**：每科总题数、已掌握数（复习做对≥3）、永久保留数，进度条展示。
  - **薄弱点分布**：按「我错在哪」归因聚合（复用 `weakPointStats`）。
- 复用现有 CSS 卡片与 `mini-bar` 样式，无新增依赖。

## 4. 数据设计（已确认）

### 4.1 变更

| 位置 | 字段 | 类型/默认 | 说明 |
|---|---|---|---|
| 每条错题 `wrongQuestions[]` | `reviewHistory` | `Array<{at:number, correct:boolean}>`，默认 `[]` | 追加式复习轨迹，写时截断至 30 条 |
| `settings` | `dailyReviewGoal` | `number`，默认 `0` | 0=未设置 |

### 4.2 迁移与备份

- `Store.migrate()` 对每条错题补齐 `reviewHistory: []`，对 settings 合并 `dailyReviewGoal: 0`（`Object.assign` 默认值天然回填）。
- 导出：`exportAll()` 整包 dump 已含新字段，无需改结构。
- 导入：`importAll()` 走 `Store.migrate(parsed.data)`，旧备份自动补齐新字段，无损兼容。
- 历史数据懒迁移：旧错题字段缺失时在 `migrate`/读取路径补齐默认值，无需逐条改写，首次改动自然落库。

## 5. 验收矩阵

| # | 项目 | 通过标准 |
|---|---|---|
| 1 | 复习记录 | 复查做对/做错后，该题 `reviewHistory` 各追加 1 条，总数含对错 |
| 2 | 轨迹显示 | 错题卡显示最近复习轨迹（✓/✗+日期）与累计正确率，历史为空时隐藏 |
| 3 | 每日目标 | 首页显示今日复习/目标；设置目标后进度随之更新；达成高亮 |
| 4 | 数据页 | 复习趋势/各科掌握度/薄弱点数据与错题簿一致 |
| 5 | 导出导入 | 导出→清空→导入后数据与图片完整；旧版备份导入后新字段被补齐 |
| 6 | 数据结构 | 单条错题 `reviewHistory.length ≤ 30` |

# 需求 REQ-20260915-010 主题切换三态改双态（日蚀式）+ 三处轻美化

> 分类：体验优化 · 影响范围：index.html + layout.css + components.css + store/ui/app/router + dashboard
> 状态：已完成（验证通过）· 最后更新：2026-09-15

## 一、背景与目标

REQ-009 实现的三态（跟随系统/浅色/深色）手动开关，用户使用后希望「更简洁、更有质感」：

1. **双态简化**：去掉「跟随系统」，只保留浅色/深色两态，切换用**日蚀式日月变形**视觉（而非普通滑块）。
2. **夜空细节**：切换到夜间背景时，星星像「被吹出来」——非直线、带失重漂浮感，静止后轻柔闪烁；天空有云层视差。
3. **轻美化**（find-animation-opportunities 克制筛选，仅加 3 处低频/首见）：看板统计数字增长动画、进度条满格轻弹、空状态图标浮动。

## 二、方向与口径（用户确认）

| 决策点 | 确认结果 |
|---|---|
| 状态数 | **双态**：`light` / `dark`；旧 `auto` 一次性归为 `light` |
| 开关位置 | 桌面：侧边栏底部（`themeToggleDesktop` 插槽）；手机：底部 Tab 栏右侧亦加一个 |
| 星星表现 | **仅切换瞬间「被吹出」漂浮 + 平时轻柔闪烁**（不做持续大幅飘动） |
| 美化范围 | +看板统计数字增长动画 · +进度条完成轻弹 · +空状态图标浮动 |

## 三、数据方案（settings.theme 取值收窄）

| 项 | 内容 |
|---|---|
| 字段 | `settings.theme`：`'light' \| 'dark'` |
| 默认值 | 由 `'auto'` 改为 `'light'` |
| 迁移 | `store.migrate` 增加一行：`if (data.settings.theme === 'auto') data.settings.theme = 'light';`（一次性归浅色） |
| 生命周期 | 随 settings 一起导出/导入、随备份恢复；不设独立存储键 |
| 回滚 | 迁移行可删，`git checkout` 可回退全部改动 |

## 四、改动清单

| 层 | 文件 | 改动 |
|---|---|---|
| 存储 | `js/store.js` | `defaultData().settings.theme: 'light'`；`migrate` 将旧 `'auto'` 迁成 `'light'` |

| 看板 | `js/views/dashboard.js` | 统计数字加 `data-count`，首次入场 `animateCounts` 数字滚动 + 满格进度条加 `is-full` 轻弹（`animated` 标记只播一次） |

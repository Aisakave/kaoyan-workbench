# 需求 REQ-20260915-011 移除手机端底部导航栏

> 分类：体验优化 · 影响范围：index.html + router.js + layout.css + components.css + base.css
> 状态：已完成（验证通过，待用户验收）· 最后更新：2026-09-15

## 一、背景与目标

用户反馈手机端底部导航栏「不美观、拥挤」（见 REQ-010 会话遗留反馈），最终决定**直接去掉**：

1. 手机端不再显示底部 Tab 栏（首页/学习计划/错题簿/资料库/数据/更多）。
2. 随底部 Tab 一同移除的还有只从 Tab 栏打开的「更多」底部面板（含科目进度/真题管理/模考成绩 + 外观开关）。
3. 手机端导航统一走**左上角汉堡菜单 → 侧栏抽屉**（8 个路由全量、含主题开关与导入导出），与桌面一致。

## 二、口径（用户本次明确指令）

| 决策点 | 结论 |
|---|---|
| 底部 Tab 栏 | **整体移除**（不隐藏、不留开关） |
| 「更多」底部面板 | 随 Tab 栏一并移除（唯一入口是 Tab 栏「更多」按钮） |
| 手机端导航方式 | 汉堡菜单 + 侧栏抽屉（现有能力，含错题红点徽标） |
| 手机端主题开关 | 侧栏抽屉底部 `#themeToggleDesktop`（现有，不再另做入口） |
| 不做项 | 不新增浮动按钮/手势导航等替代物；不改侧栏交互逻辑 |
| 数据影响 | 无（纯 UI 删除，不动 localStorage 结构） |

## 三、改动清单

| 层 | 文件 | 改动 |
|---|---|---|
| 骨架 | `index.html` | 删除 `<nav id="tabBar">` 与 `<div id="tabSheet">` 两个节点 |
| 路由 | `js/router.js` | 删除 `TAB_PRIMARY/TAB_MORE`、Tab 栏与「更多」面板渲染、`openSheet/closeSheet` 及相关点击事件；保留侧栏渲染与徽标刷新 |
| 布局 | `css/layout.css` | 删除 `.tabbar/.tab-item/.tab-badge/.tab-theme/.tab-sheet*/.sheet-*` 样式与 `tabIcoPop/tabBarIn` 动画；手机端 `.content` 去掉 `padding-bottom` 补偿 |
| 样式 | `css/components.css` | 删除手机端 toast 上移 `--tabbar-h` 的规则（回落默认 40px） |
| 变量 | `css/base.css` | 删除 `--tabbar-h`、`--tabbar-bg`（浅色/深色两处，已无引用） |

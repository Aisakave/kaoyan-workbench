# 需求 REQ-20260915-009 手动深色开关 + 导航图标选中态微动效

> 分类：功能优化 · 影响范围：index.html + base.css/layout.css + store/controller/ui/app + router
> 状态：已完成（验证通过）· 最后更新：2026-09-15

## 一、背景与目标

REQ-008（全站界面质感改造）遗留两项口径外需求，本次补做：

1. **手动深色开关**：当前深色模式仅跟随系统，用户需要能手动指定外观。
2. **图标微动效**：按克制原则（find-animation-opportunities）只做导航/Tab 选中态过渡——低频（切页才触发）、高杠杆（选中反馈更明确）。

## 二、方向与口径（用户确认）

| 决策点 | 确认结果 |
|---|---|
| 深色开关形式 | **三态**：跟随系统 / 浅色 / 深色（保留系统跟随默认能力） |
| 开关位置 | **侧边栏底部**（导出/导入按钮上方，一个按钮点击循环切换三态） |
| 图标微动效 | 仅**导航/Tab 选中态过渡**（图标轻微放大 + 指示条淡入，220ms 可中断） |

## 三、数据方案（新增 settings.theme）

| 项 | 内容 |
|---|---|
| 字段 | `settings.theme`：`'auto' \| 'light' \| 'dark'` |
| 默认值 | `'auto'`（行为与现状完全一致，跟随系统） |
| 迁移 | `store.migrate` 已用 `Object.assign(defaultData().settings, data.settings)` 回填，新增默认值后旧数据**零迁移** |
| 生命周期 | 随 settings 一起导出/导入、随备份恢复；不设独立存储键 |
| 回滚 | 删除该字段即回退为跟随系统；`git checkout` 可回退全部改动 |

## 四、改动清单

| 层 | 文件 | 改动 |
|---|---|---|
| 设计令牌 | `css/base.css` | 深色变量块从 `@media (prefers-color-scheme: dark) { :root }` 改为 `:root[data-theme="dark"]` 单一来源；背景光晕规则改挂在 `[data-theme="dark"]` 下 |
| 布局 | `css/layout.css` | 侧边栏外观按钮布局；导航/Tab 选中态微动效（图标 pop 220ms forwards + 指示条 scaleY/scaleX 淡入） |
| 骨架 | `index.html` | sprite 新增 `i-sun`/`i-moon`/`i-monitor`；sidebar-footer 新增外观按钮 `#btnTheme` |
| 存储 | `js/store.js` | `defaultData().settings` 新增 `theme: 'auto'`（migrate 自动回填） |
| 行为 | `js/ui.js` | `UI.applyTheme(mode)`：写 `html[data-theme]`、同步 `meta[name=theme-color]`、渲染按钮文案 |
| 装配 | `js/app.js` | 初始化时应用主题；绑定 `#btnTheme` 点击循环三态（auto→light→dark→auto）；`matchMedia('(prefers-color-scheme: dark)')` 监听，auto 态实时跟随系统 |

## 五、验证口径与实测结果

- `node --check`：store/ui/app/controller 全部通过。
- 真实浏览器（Edge headless + CDP）实测：
  - 三态切换：auto+系统浅色 → light（bg #f5f7fb）；系统切深色 → auto 实时跟随 dark（bg #101319）；强制 light/dark 在系统相反偏好下均正确覆盖；按钮文案与图标随三态更新。
  - 持久化：`kylc:data.settings.theme` 正确写入，刷新后恢复；切回 auto 恢复跟随系统。
  - 导航/Tab 选中态动画：`icoPop`/`tabIcoPop`（220ms）与指示条 `barGrow`/`tabBarIn` 生效。
  - 8 个路由强制深色下无 JS 异常、无横向溢出；consoleErrors / pageErrors 均为 none。

- 不做独立主题页/更多外观选项。

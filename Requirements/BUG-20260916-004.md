# [BUG] 模考成绩/真题管理表单缺输入校验（负数/0 分/分数>满分可保存）

> 编号：BUG-20260916-004-表单输入校验缺失
> 关联：REQ-20260915-001（模考成绩、真题管理视图）
> 状态：已修复
> 创建：2026-09-16
> 更新：2026-09-16

## 现象描述

- 模考成绩：分数填负数、0 分、或高于满分（如满分 100 填 150）都能保存；
- 真题管理：用时/得分/错题数可填负数；用时留空会被静默当 0 保存，无法区分「没填」与「0 分钟」。

## 复现步骤

1. 模考成绩 → 记录成绩 → 分数填 `-5` 或 `150`（满分 100）→ 保存成功
2. 真题管理 → 记录真题 → 用时填 `-10` 或留空 → 保存成功

## 影响范围

产生不合逻辑的成绩/真题数据，污染趋势图与统计展示（负分数、超满分分数）。

## 根因分析

保存逻辑只校验「非空」（模考）与「标题非空」（真题），`min="0"` 只是浏览器提示并非强制；`pastPaper.js` 用 `Number('') || 0` 把空用时静默转 0，丢失「未填写」语义。

## 修复方案

保存前统一校验数字合法性：

- `js/views/mockExam.js`：分数须为不小于 0 的数字；满分有值时须 > 0；分数不能高于满分。
- `js/views/pastPaper.js`：用时/得分/错题数任一非空值须为不小于 0 的数字；空输入存 `null`（不再静默转 0），与得分/错题数口径一致，展示仍为「–」。

非法输入用现有 `Toast.show(msg, 'warn')` 提示并中止保存。

## 验证结果

- `node --check` 语法通过。
- 校验分支核对：负数、NaN、分数>满分、满分≤0 均被拦截并提示；合法值正常保存；空字段存 null。

# 需求 REQ-20260915-004 全站视觉美化（精致学习风）

> 分类：功能优化 · 影响范围：全站（3 个 CSS + 错题簿 JS）
> 状态：已完成 · 最后更新：2026-09-15

## 一、背景与目标

现有界面功能完整、结构清晰，但视觉偏平淡（平面蓝、卡片缺层次、几乎无动效、红色统计条过重、筛选选中态颜色语义不一致）。目标是做一次**全站统一升级**，在保留现有蓝绿语义配色的前提下提升质感，让界面更精致、更有精神。

## 二、方向与口径（用户确认）

- **视觉方向**：精致学习风（保留日系留白 + 蓝绿语义色，提升阴影/圆角/层次感，突出重点数据卡）。
- **范围**：全站统一升级，含克制的入场动效与按压反馈。
- 复用现有 `find-animation-opportunities` 的克制原则：动效仅用于切页入场、弹窗/Toast/大图、按压反馈等低频或高杠杆处，**不**在全域高频渲染（局部刷新）中触发，避免失焦与抖动。

## 三、改动清单

| 层 | 文件 | 改动 |
|---|---|---|
| 设计令牌 | `css/base.css` | 阴影分级 `--shadow-1/2/pop`、缓动 `--ease-out/pop`、焦点环 `--ring`、主色/危险色加深档、背景冷暖光晕、圆角分级、滚动条/空状态/ Chip 精修、`:focus-visible` 与 `prefers-reduced-motion` |
| 布局 | `css/layout.css` | 侧栏选中渐变药丸 + 左描边指示、品牌渐变、顶栏毛玻璃加强、倒计时丸精修、底部 Tab 顶指示条 + 按压反馈、**视图切页入场动画**（`view-holder`） |
| 组件 | `css/components.css` | 按钮渐变+投影+按压、卡片圆角 18px + 阴影 + 可hover抬升、统计卡英雄渐变光晕、进度条渐变填充、输入框焦点环、radio-chip 渐变选中、弹窗毛玻璃+圆角、Toast 滑入、大图 scaleIn、Tab 渐变选中、薄弱点条/动画关键帧 |
| 行为 | `js/views/wrongBook.js` | 薄弱点最大条由刺眼红 `--color-danger` 改柔和珊瑚 `#e46a6e`；掌握度筛选选中态由绿 `chip-ok` 统一为蓝 `chip-sub`（与科目筛选一致） |

## 四、验证

- 真实浏览器（Microsoft Edge + Puppeteer，视口 1280）实测：首页 / 目标设置弹窗 / 错题簿页。
- 结果：无 JS 报错；无横向溢出错位；卡片/按钮/进度条/弹窗/薄弱点条形/筛选全部正常渲染；顶栏、渐变小写、错题簿活跃标签蓝色渐变 `#4F7CF7→#3F67E6` 生效。
- 视觉评分（AI 评估）：首页 7.9/10、弹窗 6.95/10，明显优于优化前（约 4.0/10）。

## 五、兼容性与回退

- 纯 CSS 变量平替 + 少量 JS 内联色替换，未改数据结构、未动路由/存储层；错 JS 可直接 `git checkout` 回退 CSS/错题簿改动。
- 缺少 `--shadow`（改名 `--shadow-1`）已同步全部调用点；`prefers-reduced-motion` 保留淡入、去掉位移负担。

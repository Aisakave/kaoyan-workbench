## 一、背景与目标

REQ-013 批量导入已验证成功（用户已导入 71 道错题）。用户希望把「每日错题收集」固化为标准流程，并解决混合科目场景的痛点：

| 痛点 | 现状 | 目标 |
|---|---|---|
| 默认科目数学，混合科目改起来费劲 | 预览弹窗每条单独改科目 | ①文件夹名识别科目自动默认；②「一键全部设为某科目」按钮 |
| 标题每条约手工填 | 默认「习题N」 | 标准流程文件夹名含日期，标题默认=整个文件夹名 |
| 「我错在哪」导入后补 | 固定 other | 预览弹窗每条下拉可选（默认其他） |
| 命名规范无引导 | 无 | 预览弹窗顶部显示识别结果提示 |

## 二、口径（用户已确认）

| 决策点 | 结论 |
|---|---|
| 文件夹命名规范 | 推荐 `YYYY-MM-DD-科目`，如 `2026-09-16-英语`（不强制拦截，识别不到给提示、手动改） |
| 科目识别规则 | 文件夹名含「英语」→ english、「政治」→ political、「专业」→ pro；否则默认 math（数学） |
| 日期识别 | 匹配 `YYYY-MM-DD`（支持 `- _ .` 分隔）→ 仅在预览弹窗顶部提示「已识别：日期 … · 科目 …」；识别不到提示手动设置 |
| 标题默认值 | **整个文件夹名**（如 `2026-09-16-英语`），可改、可清空 |
| 「我错在哪」 | 预览弹窗每条**下拉单选**（6 类错因 + 其他），默认其他，可改；导入后 customError 仍留空待编辑补 |
| 一键全改 | 预览弹窗顶部按钮组「全部设为：数学/英语/政治/专业课」，点击整批科目全换，个别可再微调 |
| 首次使用引导 | 首次点「批量导入」先弹引导弹窗（4 步流程 + 配对规则），底部「选择文件夹开始」；勾选「下次直接选择文件夹（不再显示本引导）」后跳过（localStorage `kylc:bulkGuide`，独立于业务数据不随备份导出）；不勾选则每次点击均先看引导 |
| 数据影响 | 无新增字段；errorTypes 由固定 `['other']` 变为预览所选单类；仅新增不覆盖 |

## 三、标准流程（每日错题收集）

1. **开始学习前**建文件夹：`YYYY-MM-DD-科目`（如 `2026-09-16-英语`；一天多科则建多个，如 `2026-09-16-专业课`）；
2. **刷题时**每道错题截 2 张图（题目图 + 解析图），**按「题→解→题→解」顺序紧挨着粘贴**进当天文件夹；
3. **学习结束**：错题簿 → 批量导入 → 选当天文件夹 → 预览确认：
   - 顶部显示识别结果（日期/科目自动带出），确认无误；
   - 标题自动 = 文件夹名；科目自动识别；「我错在哪」默认其他（需要时逐条改）；
   - 多科混合时用「全部设为」按科目批量切换；
4. **确认导入**后，每条可再点「编辑」补填真正的知识点关键词、错因细节与关键一步。

配对原理：系统按文件修改时间升序两两配对，只要「题目→解析」相邻粘贴，配对恒正确；预览可见，顺序错可移除重来。

## 四、技术方案

### 4.1 文件夹名解析

`parseFolderMeta(folderName)` → `{ subject, date }`：

- 科目：小写化后依次匹配关键词 `英语→english`、`政治→political`、`专业→pro`；无匹配返回 `math`（默认）；
- 日期：正则 `/(\d{4})[-_.](\d{1,2})[-_.](\d{1,2})/` 匹配 → `YYYY-MM-DD` 标准化；无匹配返回空。

### 4.2 预览弹窗

顶部新增（在配对说明文字下方）：

```
[已识别：日期 2026-09-16 · 科目 英语]   （未识别到日期/科目时：未识别到日期/科目，请手动设置）
[全部设为：数学] [英语] [政治] [专业课]
```

- 「全部设为」点击 → 遍历所有 `.bi-subject` 下拉设为对应 value；
- 每条 `bi-head` 在科目下拉旁新增「我错在哪」下拉：6 类错因 + 其他，默认 `other`；
- `collectEdits` 同步收集错因；`runBulkImport` 写入 `errorTypes: [所选错因]`；
- 移除条目/重渲染时保留已编辑的科目、标题、错因（读回后再删）。

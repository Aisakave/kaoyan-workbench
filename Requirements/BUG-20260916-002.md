# [BUG] 学习计划分组标题「今天」重复显示（今天 ·今天）

> 编号：BUG-20260916-002-学习计划今天重复
> 关联：REQ-20260915-001（学习计划视图）
> 状态：已修复
> 创建：2026-09-16
> 更新：2026-09-16

## 现象描述

学习计划页，截止日期为**今天**的任务分组标题显示「今天 ·今天」，看起来有两个「今天」并排；「昨天」「明天」及普通日期分组标题正常（昨天组只显示一次）。

## 复现步骤

1. 打开「学习计划」页
2. 存在截止日期为今天的任务（日期选择器选今天）
3. 分组标题显示「今天 ·今天」

## 影响范围

仅分组标题文案重复，无数据影响，不影响任务增删改查。

## 根因分析

`js/views/plan.js` 分组标题拼接逻辑：

```js
const label = isNone ? '未排期' : `${dateLabel(k)} ${k === todayStr() ? '·今天' : ''}`;
```

`dateLabel(k)`（`js/utils.js`）对今天的日期**已返回「今天」**（`daysUntil(s) === 0` → 返回 `'今天'`），分组标题又在 `k === todayStr()` 时追加一次 `·今天`，重复拼接成「今天 ·今天」。

## 修复方案

`js/views/plan.js` 分组标题直接取 `dateLabel(k)`，删除冗余追加：

```js
const label = isNone ? '未排期' : dateLabel(k);
```

`dateLabel` 已覆盖 今天/昨天/明天/普通日期 四种情形，行为完整。

## 验证结果

- `node --check` 语法通过。
- 标签逻辑单测（复刻 `dateLabel` + 修复后拼接）：
  - 今天组 → `今天`（1 次）
  - 昨天组 → `昨天`
  - 明天组 → `明天`
  - 普通日期 → `2026-12-19`
- 任务行副标题（「数学 · 今天」）不受影响，仍按原逻辑显示一次。

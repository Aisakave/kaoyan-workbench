# 需求 REQ-20260915-008 全站界面质感改造（图标/排版/弹窗/动效/深色模式）

> 分类：体验优化 · 影响范围：全站（index.html + 3 个 CSS + ui/router + 7 个视图）
> 状态：已完成（验证通过）· 最后更新：2026-09-15

## 一、背景与目标

用户反馈「现在的界面让我有点不想使用这个项目」。经四技能设计审查（emil-design-eng / find-animation-opportunities / animation-vocabulary / apple-design）诊断：动效基础已正确克制，真正劝退的是**静态质感**——全站 emoji 图标（Windows 渲染扁平、基线不一）、散落的内联样式、原生 `confirm()` 弹窗、红色徽标语义滥用、无深色模式。

目标是做一次全站质感升级，让界面「值得每天打开」。

## 二、方向与口径（用户确认）

- 档位：**P0 + P1 + P2 全量**（视觉质感 + 交互打磨 + 深色模式）。
- 图标风格：**线性描边**（Lucide 风格，stroke 1.8，currentColor）。
- 深色模式：跟随系统 `prefers-color-scheme`（不提供手动开关，尊重系统偏好）。
- 动效口径：沿用 `find-animation-opportunities` 克制原则——只补 4-5 处低频/高杠杆过渡，不动高频渲染路径（列表重建、搜索、任务勾选）。

## 三、改动清单

| 层 | 文件 | 改动 |
|---|---|---|
| 骨架 | `index.html` | 新增内联 SVG 图标 sprite（29 个 symbol，含 `i-medal`）；新增深色 `theme-color` meta；新增 SVG data-URI favicon（消除 404 控制台报错） |
| 设计令牌 | `css/base.css` | `color-scheme`；深色模式变量块（背景/表面/文字/主色/阴影/顶栏底栏背景/滚动条）；类型刻度工具类（`.stat-lg`/`.stat-xl`/`.card-title-sm`）；滚动条颜色变量化 |
| 布局 | `css/layout.css` | 切页入场提速 0.34s→0.24s（位移 8→6px）；顶栏/底栏背景改变量（深色适配）；倒计时丸文字色改 `--color-warn` |
| 组件 | `css/components.css` | Tab 计数红点语义修正（仅「待复习」红，总数中性）；错因面板展开动画（clip-path + opacity 220ms）；Tab 内容淡入 120ms；图片淡入 150ms；`.ico-svg` 对齐；`stat-value` 负字距；h-dot 补正式变量；空状态入场 |

| 视图 | 7 个视图文件 | emoji 图标全量替换为 `UI.icon()`；原生 confirm 改 `UI.confirm()`；冗余内联 `margin-bottom:14px`/字号样式清除；提示文案去装饰 emoji；排行榜奖牌 emoji → SVG 金银铜三色（`#i-medal` + gold/silver/bronze）；复习历史点 ✓/✗ → SVG check/x；「加载更多」↓ → SVG chevron-down |

## 四、验证口径与实测结果

- `node --check` 全量 13 个 JS 文件：**全部通过**（含本次会话复检）。
- 真实浏览器（Edge headless + CDP，`Emulation.setEmulatedMedia` 模拟浅/深色）实测结果：
  - 浅色：首页 svgCount 26、navIcons 16、**页面 emoji 残留 0**、无横向溢出；弹窗开/关正常。
  - 错题簿：3 Tab 渲染、图片加载 4/4、缩略图淡入类生效、自定义确认弹窗（标题/取消/确定齐全）、复习弹窗错因面板展开动画生效、**搜索框输入保持焦点**（分离刷新未回退）。
  - 排行榜：3 枚奖牌渲染为 `#i-medal` SVG，颜色金 rgb(230,168,23)/银 rgb(152,162,179)/铜 rgb(205,127,50)。
  - 深色：`--color-bg #101319`、`--color-surface #181c24`、`color-scheme: dark` 生效，body/card 背景正确。
  - 全部 8 个路由（首页/计划/科目/真题/模考/错题/资料/数据）无 JS 异常、无横向溢出。
  - 控制台与页面错误：**consoleErrors none / pageErrors none**（favicon 404 已通过 data-URI favicon 消除）。

## 五、兼容性与回退

- 纯前端样式/图标层改造：不改数据结构、不动存储 schema、不改路由参数约定；SVG sprite 为新增静态资源，无依赖。
- 深色模式仅新增 CSS 变量块，浅色为默认不变；`prefers-reduced-motion` 已有全局降级覆盖新动画。
- 回退：图标/样式改动集中于 CSS + 视图模板，可 `git checkout` 单文件回退。

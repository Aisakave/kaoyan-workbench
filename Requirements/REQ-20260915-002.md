## 背景与目标

错题簿已支持四栏归因 + 复发记忆 + 薄弱点统计，但缺少「何时该复习」的引导。新需求：让错题按**复发次数排行**（哪些题总错一目了然）、按**多久没复习**排列提醒（间隔递增，不错过任何该复习的题），复习后时间清零，形成「记录 → 复习 → 再错再练」的闭环。

核心目标：**不错过该复习的错题，高频错题一眼可见。**

### 关键决策（已确认 2026-09-15）

1. **排行口径**：按现有 `recurCount`（「再错+1」累计）降序，新建题从 0 开始，与「永久保留 ≥3 次」逻辑一致。
2. **复习语义**：复习 = 重做一遍，弹出轻量选择「做对了 / 又做错了」：
   - 做对 → `lastReviewedAt = now`、`reviewCount + 1`（间隔按表递增）
   - 做错 → `recurCount + 1`（≥3 自动标永久保留）、`reviewCount` 归零、`lastReviewedAt = now`（间隔回到 3 天重学）
3. **提醒方式**：仅侧栏/手机 Tab 红点徽标（数字 = 到期未复习数），点击直达「待复习」标签；不做弹窗打扰。
4. **间隔规则**：自适应递增，见下表。

### 间隔规则表（核心）

| 成功复习次数 reviewCount | 下一次间隔 |
|---|---|
| 0（从未复习成功） | 3 天（从未复习过按「创建日 + 3 天」首次到期） |
| 1 | 5 天 |
| 2 | 7 天 |
| 3 | 10 天 |
| 4 | 14 天 |
| 5 | 21 天 |
| ≥ 6 | 30 天（封顶） |

- **到期计算**：`lastReviewedAt` 存在 → `lastReviewedAt + 间隔[reviewCount]`；否则 → `created + 3 天`
- **逾期分级**：到期未复习 = 黄；逾期 ≥ 3 天 = 橙；逾期 ≥ 7 天 = 红
- 复习做错后 `reviewCount` 归零 → 下次回到 3 天重学

### 复习交互细节

- 错题卡片（待复习标签 / 全部列表通用）提供「✅ 复习」按钮
- 复习弹窗展示**题目图片 + 知识点标题**（便于真正重做），两个结果按钮
- 复习后 Toast 反馈：「已复习，下次 5 天后到期」/「又做错+1，下次 3 天后重学」（触发永久保留时提示）

- **实测记录的行为细节**：

  3. 排行榜同复发次数时次级按「最近更新」降序。

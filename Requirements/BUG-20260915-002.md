# [BUG] 复习弹窗右上角关闭按钮失效

> 编号：BUG-20260915-002-复习弹窗关闭按钮失效
> 关联：REQ-20260915-002
> 状态：已修复
> 创建：2026-09-15
> 更新：2026-09-15

## 现象描述

点击错题卡片「✅ 复习」打开复习弹窗后，右上角 ✕ 按钮点击无反应，无法退出，只能点「✅ 做对了 / ❌ 又做错了」才能关闭，用户被「强制」二选一。

## 复现步骤

1. 打开错题簿，任选一道到期错题
2. 点击「✅ 复习」打开弹窗
3. 点击弹窗右上角 ✕ → 无反应

## 影响范围

错题簿复习弹窗；其它视图（计划/科目/真题/模考/资料/首页）弹窗的 ✕ 正常（均已调用绑定）。

## 根因分析

`wrongBook.js` 的 `openReview()` 使用 `UI.modalShell()` 渲染带 ✕ 的标题栏，但**未调用全局的 `bindModalEvents()`**（其余 6 个视图的弹窗打开后均调用），导致 ✕ 按钮未绑定关闭事件，成为「死按钮」。

## 修复方案

`openReview()` 打开弹窗后补调 `bindModalEvents()`，与既有弹窗模式保持一致。

```js
UI.openModal(UI.modalShell('复习错题', ...), { lock: true });
...
bindModalEvents(); // 补上 ✕ 关闭绑定（修复前缺失）
```

## 验证

真实浏览器实测（http://localhost:8080/）：

- ✕ 按钮存在于弹窗右上角，点击后 `modalMask.hidden = true`、内容清空，弹窗正常关闭 ✅
- 回归：再开弹窗点「✅ 做对了」→ Toast「已复习，下次 5 天后到期」，流程不受影响 ✅

# [BUG] 学习时长只能增不能减：误录后无法清零/纠正

> 编号：BUG-20260916-003-学习时长无法减少
> 关联：REQ-20260915-001（首页学习时长记录）
> 状态：已修复
> 创建：2026-09-16
> 更新：2026-09-16

## 现象描述

首页「记录今日学习时长」误录（如多填了 30 分钟）后，把输入框改成 0 或更小值再保存，时长没有变化，无法清零或纠正。

## 复现步骤

1. 首页点「记录今日学习时长」，给某科填 30 保存
2. 再次打开，把该科改为 0，保存
3. 首页该科时长仍显示 30

## 影响范围

学习时长数据错误后无法纠正，影响首页「今日学习时长」与统计数据准确性。

## 根因分析

保存逻辑提交的是**增量**（新值 − 旧值，`js/views/dashboard.js`）：

```js
const newVal = Math.max(0, Number(inp.value) || 0);
const oldVal = log[subject] || 0;
if (newVal !== oldVal) Controller.logStudy(todayStr(), subject, newVal - oldVal);
```

输入框值被 `Math.max(0, …)` 钳制，但增量本身可为负（如 0 − 30 = −30）；`logStudy`（`js/controller.js`）的守卫 `!(minutes > 0)` 把负增量直接丢弃，导致「减少」永远不生效。

## 修复方案

`js/controller.js` `logStudy` 改为接受负增量，并对结果钳制不小于 0；0 与 NaN 仍拒绝：

```js
function logStudy(dateStr, subject, minutes) {
  if (!dateStr || !subject || !minutes || !Number.isFinite(minutes)) return;
  state.studyLogs[dateStr] = state.studyLogs[dateStr] || {};
  state.studyLogs[dateStr][subject] = Math.max(0, (state.studyLogs[dateStr][subject] || 0) + minutes);
  persist();
}
```

`dashboard.js` 无需改动（增量语义不变）。

## 验证结果

- `node --check` 语法通过。
- 边界用例 6 项全过：
  - 30 + (−30) → 0（清零 ✅）
  - 30 + (−10) → 20（减小 ✅）
  - 30 + (20) → 50（增加 ✅）
  - 0 + (0) → 不落库 ✅
  - 5 + (−10) → 钳制为 0 ✅
  - 30 + (NaN) → 拒绝不落库 ✅

## 1. 项目概述

### 1.1 背景与目标

用户正在备考 **12 月研究生考试**，需要一个简洁清爽的个人学习「备考工作台」，用于每天记录学习、复盘错题、追踪进度。核心诉求是**错题归类 + 上传图片记录错题/知识图片**。

### 1.2 产品定位

- **形态**：响应式 Web 应用（电脑浏览器 + 手机浏览器通用，手机可拍照上传错题）
- **技术**：纯前端 HTML/CSS/JS，无后端、无数据库依赖
- **存储**：结构化数据存 `localStorage`；错题/知识图片存 `IndexedDB`
- **风格**：简洁清爽、日系留白风，画面干净大方、不过度花哨

### 1.3 目标用户

个人备考者（仅本人使用，单用户、无登录）。

## 2. 核心需求（业务场景）

### 2.1 首页概览（一屏看全）

| 模块 | 内容 | 说明 |
|:---|:---|:---|
| 考研倒计时 | 距考试天数 | 自动按当前日期计算，目标日期可配置（默认 12 月第 3 个星期六前后） |
| 目标卡片 | 目标院校 + 目标分数 | 可编辑 |
| 今日任务 | 今日待办清单 | 来自学习计划，勾选完成 |
| 学习时长 | 今日记录时长 | 每科可分别计时/记时长 |
| 本周完成率 | 本周任务完成百分比 | 进度条 + 百分比 |
| 四科进度 | 英语/政治/数学/专业课 | 各科进度条 |

### 2.2 学习计划

- 任务支持：**截止时间、优先级（高/中/低）、完成状态**
- 按日期组织，可分科目
- 今日任务在首页联动展示

### 2.3 科目进度

- 四科分类：英语、政治、数学、专业课
- 各科进度管理（总进度百分比、当前阶段）

### 2.4 真题管理

- 简要记录：套数、日期、用时、得分、对错题数
- 按科目归类，形成真题记录列表

### 2.5 模考成绩

- 成绩记录（科目、分数、日期、备注）
- 趋势展示（成绩随时间的折线/列表）

### 2.6 资料库

- 存**图文资料 + 知识图片**（对应错题簿以外的资料）
- 支持打标签、搜索、按科目浏览

### 2.7 错题簿（核心功能）

完全复刻「私货本 · 四栏归因法」，并增强薄弱点分析：

```
错题记录 = 题目图片(可拍照/上传) + 四栏属性
```

| 栏 | 名称 | 内容与填法 |
|:---|:---|:---|
| ① | 题目·知识点 | 题干关键词（不抄全题），支持标签检索 |
| ② | 我错在哪 | 5 类预设：概念不清 / 计算失误 / 审题漏条件 / 记错公式 / 时间不够，可自定义补充 |
| ③ | 关键一步 | 正确路径中最容易断掉的那一步（文字描述） |
| ④ | 复发次数 | 每次重做错 +1；连错 3 次 → 标记「永久保留」 |

**增强部分：**
- **薄弱点统计**：自动按错误类型聚合，洞察"错最多"的归因类型
- **按科目分类**：英语/政治/数学/专业课各自独立错题簿
- **复习筛选**：按 未掌握 / 复发中 / 已掌握 / 永久保留 过滤（已掌握 = 复习连续做对 3 次，做错/再错 +1 打断）
- **错题复习（F-08）**：按"距上次复习"间隔递增（3/5/7/10/14/21/30 天）提醒到期；复习 = 重做（做对 → 清零并递增间隔；做错 → 再错+1 并回 3 天重学）；侧栏 + 手机 Tab 红点徽标显示待复习数
- **错题排行榜（F-08）**：按复发次数 Top 10，前三名奖牌，高频错题一目了然
- **图片压题**：错题图片上可标注题目区域（可选增强）

## 4. 技术方案

### 4.1 技术选型

| 层 | 方案 |
|:---|:---|
| UI | 原生 HTML + CSS（响应式布局，栅格 + 弹性盒） |
| 逻辑 | 原生 JavaScript（ES6+） |
| 存储 | `localStorage`（结构化数据 JSON）+ `IndexedDB`（图片 Blob） |
| 无框架 | 零依赖，避免构建步骤，直接浏览器打开 |

### 4.2 架构

```
single-page 单页应用
  ├── index.html         单入口
  ├── css/               style.css(含响应式断点)
  ├── js/
  │   ├── store.js       localStorage / IndexedDB 封装层
  │   ├── router.js      页面切换(Sidebar, 无路由库)
  │   ├── app.js         页面渲染与事件绑定
  │   └── utils.js       倒计时/日期/进度/统计工具
  └── assets/            图标(可选 inline SVG)
```

### 4.3 数据模型

```jsonc
// settings（目标配置）
{ examDate: "2026-12-19", school: "示例大学", targetScore: 380 }

// tasks（学习计划）
{ id, subject, title, dueDate, priority: "high|mid|low", done: bool, createdAt }

// subjectProgress（科目进度）
{ subject: "math", percent: 60, stage: "一轮复习" }

// pastPapers（真题记录）
{ id, subject, title, date, usedTime, score, wrongNum }

// mockExams（模考成绩）
{ id, subject, score, date, note }

// materials（资料库）
{ id, subject, title, tags: [], images: [blobId..], note }

// wrongQuestions（错题簿·核心）
{ id, subject, title, errorType, customError,
  keyStep, recurCount, permanent: bool, reviewCount, lastReviewedAt,
  images: [blobId...], created, updated }
```

## 5. 非功能需求

| 类别 | 需求 |
|:---|:---|
| 响应式 | ≥ 1024px 桌面多栏；< 768px 手机单栏、触屏友好 |
| 容错 | 图片过大可压缩提示；存储满时提示导出 |
| 数据安全 | 提供「导出 / 导入」全部数据（JSON）与图片备份 |
| 性能 | 无框架，秒开；IndexedDB 异步读写不阻塞 UI |
